SCOPE AND DESIGN
Only the homepage is built, as required for this phase. The five navigation
items match Project 2-1. Future-page links use href="#", as permitted.
The homepage follows the submitted wireframe: header, horizontal navigation,
hero, welcome/button, four category links, featured tip, and footer.
Fluid sizing uses a 96% centered body with a 1200px maximum, percentage
navigation and column widths, scalable images, and floats with clearing.
This adapts the publisher's Chapter 8 fluid application. No framework is used.
Planned colors and fonts are retained. The original illustration is a temporary
visual asset in place of the planned photograph. No contact email was supplied;
add the real address when the contact content is ready.

BEFORE SUBMISSION
1. Open index.html to preview the homepage.
2. Validate index.html at https://validator.w3.org/#validate_by_upload.
3. Validate styles.css at https://jigsaw.w3.org/css-validator/#validate_by_upload.
4. Create a new GitHub repository (for example green-balcony).
5. Upload index.html, styles.css, and the assets folder to the repository root.
6. In Settings > Pages, select Deploy from a branch, main, / (root), and save.
7. When deployment completes, open the homepage and check the styles/images.
8. Submit the live homepage URL shown by GitHub Pages to the assignment.

Deployment and official W3C validation must be completed before final submission.
This ZIP is a source package, not a substitute for the required live URL.
